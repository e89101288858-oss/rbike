# RBike CRM

Простая CRM-система для учета аренды электровелосипедов.

## Возможности MVP
- учет клиентов;
- учет парка велосипедов;
- открытие/закрытие аренд;
- автоматический расчет стоимости по времени аренды;
- дашборд с ключевыми метриками.

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

После запуска откройте `http://127.0.0.1:5000`.
